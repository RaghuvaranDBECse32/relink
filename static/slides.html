Sun & Earth windows at lunar south-pole sites. Side-by-side comparison table + elevation charts.

🎮

Lunar Relay Game

Match-3 tower defense: teach link-window timing interactively. Jabali Game Jam entry.

💬

Chat

Independent messenger: accounts, contacts, groups, block/report, export & delete.

Paste any suspicious link or message → AI explains risk indicators + 8 interactive lessons.

🔍

Verify

Stale-answer detector: Tavily + LLM judge → CURRENT / STALE / CONFLICTING / UNVERIFIED.

How We Built It

Lightweight architecture · open-source MVP

🐍

Python 3.10+

stdlib http.server + numpy for ephemeris. No frameworks. 29 unit tests. Single file server.

⚡

Vanilla JS

No CDN, no build step, CSP-safe. Canvas for elevation charts. Full SPA in one file.

🗄️

SQLite + scrypt

Zero-config database. Signed expiring tokens. Rate limiting. Security headers on every response.

🚀

Railway Deploy

One command: python server.py. Docker + Cloud Run ready. No build pipeline needed.

🤖

Gemini / Bifrost

Optional LLM judge for Verify module. Works without keys — returns UNVERIFIED honestly.
